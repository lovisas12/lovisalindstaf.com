# lovisalindstaf.com

Portfolio site for Lovisa Lindstaf. Static HTML, CSS and JavaScript, hosted on GitHub Pages at [lovisalindstaf.com](https://lovisalindstaf.com).

- `index.html` – page structure and static copy
- `styles.css` – all styling (colour tokens at the top)
- `main.js` – project, capability and experience content plus interactions (case-study overlay, nav, animations)
- `assets/` – images and video

Run locally with any static server, for example `python3 -m http.server`.
